# Dataset

Source: [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic/data).

Only `train.csv` is permitted. From the project directory, run:

```bash
.venv/bin/python data.py
```

This fetches the file directly from Kaggle if it is absent and records the fixed split.
Authentication and competition access are required. Raw data is excluded from Git.
